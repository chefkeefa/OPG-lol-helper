# Rift Pulse 0.3 — личный клон DPM для League of Legends

Десктоп-программа (Electron + React) по образцу приложения DPM: рамка окна со своими кнопками,
дашборд со статистикой и графиками, история матчей, чемпионы, текущая игра и оверлей
с таймерами объектов. Все переходы анимированы: появление карточек, рисующиеся графики,
счётчики, скользящие переключатели, раскрытие матчей.

## Что умеет

- **Свой аккаунт без ключа.** Программа находит запущенный клиент League of Legends
  (как оригинал: через процесс `LeagueClientUx.exe` или файл `lockfile`) и берёт оттуда
  профиль, ранги, историю матчей и мастерство. Статус клиента виден в шапке
  («В лобби», «Выбор чемпионов», «В игре»).
  Клиент отдаёт только последние 20 игр, поэтому все увиденные игры остаются в кеше на диске
  и история растёт с каждой партией; с ключом Riot API старые игры подтягиваются через match-v5.
- **Дашборд**: 8 метрик с графиками «последние 5 игр против среднего», фильтр по роли,
  фильтр очереди (Solo/Flex/ARAM/Normal), лучшие игры, последняя игра, оверлей, мастерство,
  «Линза» (крупный график одной метрики), ранг, список матчей с оценкой MVP/ACE, чемпионы и роли.
- **История матчей**: клик раскрывает табло всех 10 игроков (KDA, урон, CS, обзор, предметы, оценка).
- **Чемпионы**: таблица с сортировкой и мастерство.
- **Текущая игра**: оба состава, счёт, предметы и таймеры объектов в реальном времени
  (Live Client Data API игры, порт 2999).
- **Оверлей**: прозрачное окно поверх игры с таймерами дракона, личинок, герольда, барона и
  древнего дракона. Появляется само в начале матча. `Ctrl+Shift+O` показывает и скрывает его.
  Нужен режим окна «Без рамки» (в полноэкранном режиме Windows окна поверх игры не показывает).
- **Тир-лист** по ролям (S+…D), винрейт, пикрейт, банрейт, выбор патча. Данные считает сама программа:
  в фоне скачивает ранговые игры Master, Grandmaster и Challenger вашего региона через официальный Riot API
  и хранит только итоги (папка `stats` в данных программы).
- **Билды и руны** для каждого чемпиона и роли: полная страница рун с осколками, альтернативные страницы,
  заклинания, стартовые предметы, основная сборка, ботинки, предметы поздней игры, порядок навыков,
  сложные и лёгкие матчапы. Кнопки «Всё в клиент», «Руны», «Предметы», «Заклинания».
- **Выбор чемпиона**: программа сама открывает билд вашего чемпиона, а после фиксации выбора импортирует
  руны и набор предметов в клиент (и по желанию заклинания). Всё переключается в настройках.
- **Матчапы**: винрейт против каждого противника на линии, разница со средним, сравнение «один на один».
- **Записи игр**: запись экрана со звуком начинается сама, когда загрузится матч, и заканчивается вместе с ним.
  Убийства, смерти, мультикиллы и объекты отмечаются на шкале, из любого момента вырезается клип.
  Видео сохраняются в «Видео\Rift Pulse» (mp4), старые удаляются при превышении лимита папки.
- **Наблюдение**: избранные игры региона, поиск игры по Riot ID, проверка топ-30 Challenger;
  кнопка «Смотреть» запускает наблюдение в клиенте LoL.
- **Коллекция**: ваши чемпионы и образы из клиента, мастерство, бесплатные чемпионы недели.
- **Data Studio**: свои графики по вашим играм (линия, столбцы, точки, любые показатели и группировки),
  которые можно сохранить на доску.
- **Оверлей «вы и ваше среднее»**: в игре рядом с таймерами показывает CS/мин, KDA, KP и обзор
  против ваших средних на этом чемпионе.
- **Поиск других игроков** по Riot ID (`Ctrl+K`). Для поиска и лидеров нужен ключ Riot API (Настройки).

## Запуск

Нужен Node.js 20+ и Windows (подключение к клиенту LoL работает только там).

```bash
npm install
npm run app      # режим разработки: окно программы + горячая перезагрузка
```

Собрать обычный .exe:

```bash
npm run dist     # результат в папке release/ (установщик Rift-Pulse-Setup-x.y.z.exe)
```

Веб-версия без Electron (только поиск через Riot API и демо): `npm run dev`.

## Автообновление

Код лежит в публичном репозитории `chefkeefa/OPG-lol-helper`. Каждый push в `main` запускает
GitHub Actions (`.github/workflows/release.yml`): сборка на Windows, установщик публикуется
в GitHub Releases с версией `0.4.<номер запуска>`.

Установленная программа проверяет обновления при запуске и каждые 30 минут, скачивает их
в фоне и ставит при выходе. В боковой панели появляется кнопка «Перезапустить», чтобы
обновиться сразу. Ключ Riot API и настройки лежат в `%APPDATA%\rift-pulse` и не теряются.

Первый раз программу нужно поставить вручную из раздела Releases, дальше всё приходит само.

## Ключ Riot API

Нужен для тир-листа, билдов, матчапов, поиска игроков, лидеров и наблюдения. Свой аккаунт, история,
запись игр, оверлей и коллекция работают без ключа. Ключ выдают на https://developer.riotgames.com:
dev-ключ бесплатный, но живёт 24 часа; для постоянной работы оформите там же Personal API Key.
Вставьте ключ в «Настройки → Ключ Riot API». Первые результаты тир-листа появятся после ~150 игр,
dev-ключ позволяет собирать примерно 1000–1500 игр в час.

## Чем отличается от DPM

- Статистика своя: её собирает ваша копия программы с вашим ключом, поэтому в первые часы выборка меньше,
  чем у DPM, и растёт со временем.
- Оверлей и запись не встраиваются в процесс игры (это риск для аккаунта из-за античита Vanguard):
  оверлей это отдельное прозрачное окно, запись идёт через захват экрана. Для оверлея нужен режим окна
  «Без рамки».

## Структура

```
electron/main.cjs      окно, настройки, опрос клиента и игры, оверлей, IPC
electron/lcu.cjs       подключение к клиенту LoL (LCU) и Live Client Data API
electron/riot.cjs      запросы к Riot API с соблюдением лимитов ключа
electron/collector.cjs фоновый сбор игр Master+ и расчёт статистики
electron/builds.cjs    рекомендуемый билд и импорт рун, предметов, заклинаний в клиент
electron/recorder.cjs  запись игры, моменты, клипы (ffmpeg)
electron/preload.cjs   мост window.rp для интерфейса
src/api/               client.ts (клиент LoL), riot.ts (Riot API), normalize.ts (матчи → единый формат)
src/lib/               stats.ts, objectives.ts (таймеры), ddragon.ts (картинки)
src/components/        ui.tsx (анимированные примитивы), TitleBar, Sidebar, OverlayTimers
src/pages/             Dashboard, Matches, Champions, Studio, TierList, Champion, Matchups, Leaderboards,
                       Live, Recordings, Spectate, Collections, Overlays, Settings
```
